# Mr. Toot header image

`public/mr-toot.png` is a transparent cutout of the Mr. Toot silhouette in the older Mason City Chamber of Commerce logo.

Source: https://masoncityia.com/wp-content/uploads/2019/05/Winner-Release-for-website.pdf (first embedded image on page 1).

The source logo was extracted with `pdfimages`. Imagegen removed the lettering and white background to isolate the mascot for the website header. The original silhouette's brown color was retained.

No open license was verified. This asset is not covered by any general license for the website's code.

Destination: https://en.wikipedia.org/wiki/Mason_City,_Iowa
